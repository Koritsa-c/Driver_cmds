# Driver_cmds

Я создал небольшую утилиту,которая позволяет управлять драйверами. 

!!!ВАЖНО:Программа может сломать ваши драйвера, будьте осторожны.



Как использовать:
  Запустите компьютер в тестовом режима для возможности использовать функцию загрузки драйверов, затем запустите программу и нажмите на название драйвера, с которым вы хотите взаимодействовать
